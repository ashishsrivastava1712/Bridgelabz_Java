# Bridgelabz Java

Java assignments and practice problems completed as part of the BridgeLabz training program. Assignments are taken from Google Classroom (GCR).

---

## Repository Structure

- **main**: README and daily task updates
- **develop**: empty Java project skeleton
- **feature/coreProgramming**: Java Programming Elements, Arrays, Methods, Strings
- **feature/objectOrientedProgramming**: OOPs concepts and problems
- **feature/DataStructure**: Linked List, Sorting, Searching, Stacks, HashMap
- **feature/Collections**: Collections, Generics, Streams, Lambda, Regex, Exception Handling
- **feature/IODesignPatternsMultiThreads**: File IO, Annotations, Design Patterns, Multithreading
